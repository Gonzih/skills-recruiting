# @gonzih/skills-recruiting

Recruiting skills for [Claude Code](https://claude.ai/code).

## Skills

| Skill | Description |
|-------|-------------|
| `/job-description` | Write inclusive, effective job descriptions |
| `/outreach-message` | Write personalized candidate outreach messages |
| `/interview-scorecard` | Create structured interview scorecards |
| `/offer-negotiation-guide` | Write offer negotiation guidance and counteroffers |

## Installation

```bash
claude mcp add @gonzih/skills-recruiting
```

Or install via npm and add to your Claude Code config:

```bash
npm install -g @gonzih/skills-recruiting
```

## Usage

In Claude Code, invoke any skill with its slash command:

```
/job-description Senior Backend Engineer, Go/Kubernetes stack, remote-first
/outreach-message Jane Doe, open-source contributor to etcd, targeting Staff SRE role
/interview-scorecard Staff Engineer, system design round, 60 minutes
/offer-negotiation-guide candidate perspective, base $180k + 0.1% equity, competing offer at $195k
```
